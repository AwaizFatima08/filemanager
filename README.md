# File Manager (HomiLabs)

A simple file manager for Android phones, built with Flutter.

- Browse internal storage, SD cards and USB drives; shortcuts to Downloads, Camera, Pictures, Documents, Music, Videos.
- Sort by name, date, size or type (tap again to reverse).
- Group into sections by file type, date, size or first letter.
- Copy, move, rename, delete and share — for one file (⋮ menu) or many (long-press to select).
- Search inside a folder, create folders, show or hide hidden files, image thumbnails.

```bash
flutter analyze && flutter test
flutter build apk --release
```
