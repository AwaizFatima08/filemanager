File Manager

Additional terms for File Manager · updated 9 November 2026

Deleting is permanent

File Manager has no recycle bin. When you delete a file or folder, and confirm, it is removed from your phone straight away, and a folder is deleted with everything inside it. Keep a backup of anything important (photos, documents, chats). HomiLabs is not responsible for files lost by deleting, moving or renaming them.

Copying and moving

File Manager never overwrites a file: if the target folder already has one with the same name, the new copy is saved as "name (1)". A move to another drive (for example from the phone to an SD card) is done by copying and then deleting the original, so do not remove the card or close the app until it has finished. If the phone runs out of space or a card is removed part-way, some items may be left in both places or not copied; the app lists anything that failed.

Folders Android protects

Android does not let any file manager open some folders, such as Android/data and Android/obb on newer phones, and system files. Changing files that other apps use can stop those apps from working, so only do it if you know what the file is for.
