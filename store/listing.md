## Full description
File Manager keeps your phone's files tidy with a clean, simple screen and big, clear buttons.

SEE EVERYTHING
• Browse internal storage, SD cards and USB drives
• Shortcuts to Downloads, Camera, Pictures, Documents, Music and Videos
• Picture previews, file sizes and dates at a glance
• Search inside any folder

SORT AND GROUP
• Sort by name, date, size or type — tap again to reverse the order
• Group files into sections: by file type (Images, Videos, Audio, Documents, Archives, Apps), by date (Today, Yesterday, This week…), by size, or by first letter
• Your choice is remembered

COPY, MOVE AND SHARE
• Long-press to select several files at once
• Copy or move, then open any folder and tap "Paste here"
• Never overwrites: a file with the same name is saved as "name (1)"
• Rename, delete (with a clear warning) and see file details
• Share photos, documents and more with any app on your phone

PRIVATE BY DESIGN
• No account, no login, no analytics
• Your files never leave your phone unless you share them

File Manager needs "All files access" on Android 11 and newer so it can show and manage your files. It is free and supported by ads.

Privacy policy: https://tools.homilabs.org/privacy#filemanager
